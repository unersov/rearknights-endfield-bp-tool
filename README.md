# Arknights: Endfield Blueprint Planner / 终末地蓝图规划工具

这是一个用于《明日方舟：终末地》的非官方生产规划与蓝图辅助工具。

本项目旨在帮助玩家更方便地查看和规划游戏中的物品、设施、配方、生产链与蓝图布局，减少手动计算和反复查表的成本。

#### 目前项目仍处于早期开发阶段，功能还未完善，bug有很多

## 主要功能

- 查看物品、材料、液体、设施和配方信息
- 规划生产链和设施布局
- 辅助计算生产关系、输入输出和产物需求
- 支持终末地蓝图规划相关的数据整理与展示
- 为后续自动化规划、生产模拟、电力模拟和布局优化提供基础

## 项目目标

本项目的目标是制作一个更直观、更易维护的终末地生产规划工具，方便玩家根据游戏内数据快速设计生产流程和基地布局。

未来希望逐步完善：

- 自动生成生产链
- 自动计算设施需求
- 自动规划布局和运输关系
- 支持更完整的蓝图导入、导出和分享
